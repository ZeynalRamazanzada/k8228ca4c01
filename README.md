# Kelime Kartları

Kartlar, Öğren, Test ve Eşleştir modlarıyla İngilizce kelime çalışma uygulaması.
Tek bir HTML dosyası; sunucu, hesap ve kurulum gerektirmez.

**iPhone'a eklemek için:** adresi Safari'de aç → Paylaş → Ana Ekrana Ekle.
İlk açılıştan sonra internet olmadan da çalışır.

Eklediğin kelimeler yalnızca kendi cihazında saklanır; bu depoya gönderilmez.
Ayarlar bölümünden yedek alabilir, yedeği başka bir cihazda geri yükleyebilirsin.
